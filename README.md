Campus Connect — Alumni Mentorship & Career Guidance System

Campus Connect is a student-focused website concept that connects college students with alumni mentors. Students can explore career paths, find mentors by field or guidance topic, and get support with goals such as resume reviews, interview preparation, and portfolio feedback.

This project is built as a frontend demonstration using HTML, CSS, and JavaScript. Any sign-in, booking, registration, or saved data shown in the demo is simulated in the browser and is not connected to a live backend.

Features

- Search and filter alumni mentors by career field, skills, and guidance topics.
- View mentor profiles with career information, experience, and availability.
- Save mentors for later.
- Request a sample mentorship session through a booking flow.
- Explore career resources for resumes, interviews, internships, and portfolios.
- Browse alumni events and try the sample registration interaction.
- Track career goals and action items.
- Submit demo feedback after a mentorship session.
- Responsive layout for desktop, tablet, and mobile screens.
- Navy, teal, and warm neutral visual theme designed for a welcoming campus-to-career experience.

Getting Started

Run locally

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in a modern web browser.

No build tools or package installation are required for the static frontend version.

Demo Notice

This is an educational frontend project. Without a backend, user accounts, mentor availability, bookings, event registrations, and feedback are not sent to a server. Demo information may be stored only in the current browser when local storage is implemented. Do not enter real personal or sensitive information.
